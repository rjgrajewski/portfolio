# Knowledge corpus

This is where the agent's knowledge corpus lives — `core/`, `topics/`,
`star/`, and `manifest.json`, per [docs/ARCHITECTURE.md § Knowledge / content
retrieval](../docs/ARCHITECTURE.md#knowledge--content-retrieval).

Empty for Phase 0. Seed content lands in **Phase 2** (minimal, real content
for the flagship topics — see [docs/ROADMAP.md § Phase
2](../docs/ROADMAP.md#phase-2--agent-mvp-text-only)); the full authoring pass
across every topic and layer is **Phase 8**.

English only — see [docs/ARCHITECTURE.md § Bilingual EN / PL
support](../docs/ARCHITECTURE.md#bilingual-en--pl-support). The authoring
guide (layering, tone, length rules) replaces this file once Phase 8 starts.
